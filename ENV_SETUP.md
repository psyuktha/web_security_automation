# Environment Variables Setup Guide

After removing hardcoded content, configure these environment variables for proper scanning:\n\n## Quick Setup\n\n### Copy to `.env` file\n```bash\n# ============================================\n# TARGET CONFIGURATION\n# ============================================\n# Username for authentication (if target requires login)\nTARGET_USERNAME=admin\n\n# Password for authentication (leave empty if no auth needed)\nTARGET_PASSWORD=\n\n# Security level for DVWA (low/medium/high/impossible)\nTARGET_SECURITY_LEVEL=low\n\n# ============================================\n# AI/ML FEATURES (Optional but recommended)\n# ============================================\n# Gemini API Key for payload generation and mitigation\n# Get from: https://makersuite.google.com/app/apikey\nGEMINI_API_KEY=\n\n# Alternative mitigation API key (defaults to GEMINI_API_KEY)\n# MITIGATION_API_KEY=\n\n# ============================================\n# ZAP INTEGRATION\n# ============================================\n# ZAP server URL (must be running before scans)\nZAP_API_URL=http://localhost:8090\n\n# ZAP API Key (if configured in ZAP)\n# ZAP_API_KEY=\n\n# ============================================\n# MONGODB\n# ============================================\nMONGODB_URL=mongodb://localhost:27017/security_scanner\n\n# ============================================\n# SERVER\n# ============================================\nPORT=3001\n```\n\n## Minimum Configuration for Scanning\n\n### Scenario 1: No Authentication Needed\n```bash\nGEMINI_API_KEY=your-gemini-key\nZAP_API_URL=http://localhost:8090\nMONGODB_URL=mongodb://localhost:27017/security_scanner\n```\n\n### Scenario 2: With Target Authentication\n```bash\nTARGET_USERNAME=testuser\nTARGET_PASSWORD=testpass123\nGEMINI_API_KEY=your-gemini-key\nZAP_API_URL=http://localhost:8090\nMONGODB_URL=mongodb://localhost:27017/security_scanner\n```\n\n### Scenario 3: DVWA Scanning\n```bash\nTARGET_USERNAME=admin\nTARGET_PASSWORD=password\nTARGET_SECURITY_LEVEL=low\nGEMINI_API_KEY=your-gemini-key\nZAP_API_URL=http://localhost:8090\nMONGODB_URL=mongodb://localhost:27017/security_scanner\n```\n\n## Getting API Keys\n\n### Gemini API Key\n1. Go to https://makersuite.google.com/app/apikey\n2. Click \"Create API Key\"\n3. Copy the key to `.env` as `GEMINI_API_KEY`\n\n### ZAP Setup\n```bash\n# Start ZAP with API\nzap.sh -config api.disablekey=false -port 8090\n\n# Test ZAP connection\ncurl http://localhost:8090/JSON/core/action/newSession\n```\n\n## Verify Configuration\n\n```bash\n# Check if environment variables are set\necho $GEMINI_API_KEY      # Should show your API key\necho $ZAP_API_URL         # Should show http://localhost:8090\necho $TARGET_USERNAME     # Should show your username\n```\n\n## Troubleshooting\n\n### CSRF Token Not Found\n- Added support for: `user_token`, `csrf_token`, `token`, `_token`, `csrf`, `authenticity_token`, `_csrf`\n- Check target app uses one of these field names\n\n### Login Fails\n- Ensure `TARGET_USERNAME` and `TARGET_PASSWORD` are correct\n- Check if target uses alternative login paths\n- Verify login form field names (`username`, `password`)\n\n### ZAP Connection Error\n- Start ZAP: `zap.sh -config api.disablekey=false -port 8090`\n- Verify URL: `curl http://localhost:8090/JSON/core/action/newSession`\n- Update `ZAP_API_URL` if ZAP runs on different port\n\n### AI Features Not Working\n- Verify `GEMINI_API_KEY` is set correctly\n- Check Gemini quota hasn't been exceeded\n- Fallback payloads will be used if API fails\n\n## Now Ready!\n\nYour scanner is configured for actual dynamic scanning of any target. No more hardcoded values! 🎯\n
